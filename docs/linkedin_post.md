# LinkedIn Post Draft

Pracuje nad kolejnym projektem do portfolio Data Analyst / BI Analyst: **FMCG Product Offer & Pricing Analysis**.

Projekt opiera sie na bazie SQL Server zawierajacej 2,910 rekordow oferty produktowej. Analizuje dostepnosc produktow, ceny netto i brutto, stawki VAT, jednostki miary, cenniki alternatywne oraz jakosc danych.

Zakres projektu:

- SQL Server / SSMS
- analiza oferty produktowej
- kontrola jakosci danych
- porownanie cen netto i brutto
- analiza stawek VAT
- widoki SQL pod raportowanie
- dashboard Power BI

Najwazniejszy cel: pokazac, jak dane produktowe moga wspierac sprzedaz, zakupy, controlling i zarzadzanie oferta w firmie hurtowej lub sklepowej.

To praktyczny projekt oparty na realnym kontekście biznesowym, a nie na przypadkowym zbiorze testowym.
